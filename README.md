# Snake

Mini-jeu web inspire de Snake.
Projet perso, joue en local sur ordinateur, au clavier.

## Lancer le jeu

Prerequis: Node.js 20.19+ (ou 22.12+) et npm. Un `.nvmrc` est fourni.

```
npm install
npm run dev
```

Puis ouvrir l'URL affichee dans le terminal (par defaut `http://localhost:5173`).

## Controles

- Direction: fleches directionnelles, ou le bloc de touches WASD
  (soit **ZQSD** sur un clavier AZERTY: le binding se fait sur la position physique
  de la touche, pas sur la lettre imprimee)
- `R`: relancer un run
- `Espace`: pause / reprise pendant un run

Le reste se decouvre en jouant.
